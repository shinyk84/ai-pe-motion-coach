# AI 체육 동작 코치

초등 체육수업에서 카메라로 동작을 연습할 수 있는 정적 웹앱입니다.

- 서비스: <https://shinyk84.github.io/ai-pe-motion-coach/>
- 저장소: <https://github.com/shinyk84/ai-pe-motion-coach>
- 개발 인수인계: [DEVELOPMENT.md](./DEVELOPMENT.md)

## 포함된 동작

- 스쿼트
- 런지
- 팔 벌려 뛰기
- 양팔 올리기

각 동작은 MediaPipe Pose가 찾은 2차원 관절 위치를 바탕으로 간단한 피드백과 반복 횟수를 제공합니다. 전문적인 운동 또는 의료 진단 도구가 아닙니다.

## 연습 전 설정

카메라를 시작하기 전에 다음을 선택할 수 있습니다.

- 연습할 동작 (스쿼트, 런지, 팔 벌려 뛰기, 양팔 올리기)
- 전면/후면 카메라
- 준비 시간 (5초, 10초, 15초 · 기본값 10초)
- 음성 안내 켜기/끄기
- 원거리 모드 켜기/끄기
- **음성 시험** 버튼으로 목소리가 잘 들리는지 미리 확인

동작을 고르면 바로 아래 안내 카드에 촬영 방향(정면/측면), 권장 거리, 수행 단계가 표시됩니다. **설명 듣기** 버튼을 누르면 이 안내를 음성으로 들을 수 있습니다.

## 카메라 시작과 준비 카운트다운

**카메라 시작**을 누르면 다음 순서로 진행됩니다.

1. 카메라 권한 요청 및 영상 준비 대기
2. 선택한 동작 이름과 촬영 안내를 화면과 음성으로 안내
3. 선택한 준비 시간 동안 카운트다운 (마지막 3초는 "3, 2, 1, 시작"을 화면과 음성으로 안내)
4. 카운트다운이 끝난 뒤부터 횟수와 자세 판정 시작

카운트다운 화면에서 **바로 시작**을 누르면 대기 없이 바로 연습을 시작할 수 있고, **취소**를 누르면 카메라를 끄고 설정 화면으로 돌아갑니다. 카운트다운 중에는 동작 횟수가 올라가지 않습니다.

## 원거리 모드

교실 뒤쪽이나 운동장처럼 학생이 카메라에서 멀리 떨어져 있을 때, **원거리 모드**를 켜면 카메라 화면 위에 큰 글자로 피드백이 표시됩니다.

- 화면 하단에 반투명 배경과 큰 글씨로 피드백 문구 표시 (예: "조금 더 내려가요", "가슴을 들어요", "좋아요! 3회 성공")
- 화면 모서리에 성공 횟수를 크게 표시
- 성공(녹색 ✅), 일반 안내(파랑 ℹ️), 주의(주황 ⚠️) 상태를 색상과 아이콘으로 함께 구분
- 하단 측정 대시보드는 원거리 모드에서 자동으로 작게 줄어듭니다

몸이 화면 밖으로 나가거나 잘 보이지 않으면 "몸 전체가 보이게 해주세요", "한 걸음 뒤로 가세요" 같은 안내가 큰 문구와 음성으로 표시됩니다.

## PC·교실 화면으로 스마트폰 카메라 보내기

교실 PC나 프로젝터에는 보통 카메라가 없습니다. 이 기능을 쓰면 학생의 스마트폰 카메라 화면(관절선 포함)을 같은 와이파이의 PC 화면에 그대로 띄울 수 있습니다. 별도 서버 없이 두 기기가 직접(P2P, WebRTC) 연결되며, 영상은 어느 서버도 거치지 않습니다.

**PC(받는 쪽)에서:**

1. 화면 위쪽의 **"폰 카메라 받기 (PC·교실용)"** 탭을 누릅니다.
2. **연결 시작 (QR 만들기)**를 누르면 QR코드가 생깁니다.
3. 스마트폰이 QR코드를 스캔하면 나오는 코드를, 스마트폰에서 복사해 받아 아래 입력창에 붙여넣고 **연결 완료**를 누릅니다.
4. 잠시 후 스마트폰 화면이 그대로 이 화면에 나타납니다.

**스마트폰(보내는 쪽)에서:**

1. 평소처럼 동작을 고르고 **카메라 시작**을 눌러 연습을 시작합니다.
2. "PC·교실 화면으로 보내기" 카드에서 **PC와 연결하기 (QR 스캔)**를 누르고, PC 화면의 QR코드를 카메라로 비춥니다.
3. 화면에 뜨는 코드를 **코드 복사** 버튼으로 복사한 뒤, 평소 두 기기 사이에 글자를 옮기던 방법(카카오톡 나에게 보내기, 문자, 이메일 등)으로 PC에 전달해 붙여넣습니다.

연결되면 성공 횟수와 자세 피드백도 PC 화면 위에 실시간으로 함께 표시됩니다(원거리 모드와 같은 방식). 두 기기가 같은 와이파이에 있어야 하고, 학교 와이파이가 기기 간 통신을 막아둔 경우(AP/클라이언트 격리) 연결이 안 될 수 있습니다.

## 다른 컴퓨터에서 시작하기

Git을 설치한 뒤 터미널에서 다음 명령을 실행합니다.

```powershell
git clone https://github.com/shinyk84/ai-pe-motion-coach.git
cd ai-pe-motion-coach
python -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다. 처음 커밋할 때 Git이 작성자 정보를 요구하면 해당 컴퓨터에서 다음과 같이 설정합니다.

```powershell
git config user.name "shinyk84"
git config user.email "GitHub에 등록한 이메일"
```

작업 전에는 `git pull`, 작업 후에는 아래 순서로 GitHub에 반영합니다.

```powershell
git status
git add index.html README.md DEVELOPMENT.md
git commit -m "변경 내용을 설명하는 메시지"
git push
```

## 로컬 실행

카메라는 보안 연결에서만 안정적으로 사용할 수 있으므로 파일을 직접 열기보다 로컬 웹 서버를 사용합니다.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 같은 와이파이의 스마트폰에서 PC의 IP 주소를 HTTP로 여는 방식은 카메라 권한이 제한될 수 있으므로, 스마트폰 테스트에는 위의 GitHub Pages HTTPS 주소를 사용합니다.

## 배포

`main` 브랜치 최상위 폴더가 GitHub Pages에 연결되어 있습니다. `index.html`이 저장소 최상위에 있어 별도 빌드 과정은 필요하지 않으며, `main`에 푸시하면 잠시 후 서비스에 자동 반영됩니다.

## 개인정보

현재 구현은 영상을 녹화하거나 서버로 업로드하지 않습니다. 카메라 영상은 브라우저에서 실시간 자세 분석에만 사용합니다. "PC·교실 화면으로 보내기" 기능을 사용하면 영상이 같은 와이파이의 다른 기기로 직접(P2P) 전송되지만, 이 경우에도 서버에 저장되거나 업로드되지 않습니다.
